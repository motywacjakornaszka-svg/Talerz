Dostawca AI do rozpoznawania posiłków

Google Gemini

Klucz jest darmowy, a Gemini API ma darmowy limit zapytań na wybranych modelach (wystarczy na codzienne zdjęcia posiłków). W darmowym planie Google może używać przesłanych danych do ulepszania usług.

🔑 Utwórz klucz w Google AI Studio ↗
  1. Zaloguj się kontem Google i zaakceptuj regulamin.
  2. Kliknij Create API key (albo skopiuj klucz utworzony automatycznie).
  3. Wklej klucz (zaczyna się od AIza) poniżej.
Dokumentacja modeli: ai.google.dev/gemini-api/docs/models

Claude (Anthropic)

Claude API jest płatne za użycie (przedpłacone kredyty w Claude Console). Jedno zdjęcie posiłku to zwykle ułamek centa do kilku centów, zależnie od modelu. Uwaga: subskrypcja Claude Pro/Max na claude.ai nie obejmuje API – to osobne konto rozliczeń.

🔑 Utwórz klucz w Claude Console ↗
  1. Zaloguj się na platform.claude.com i doładuj kredyty w Billing.
  2. W Settings → API keys kliknij Create key. Ustaw limit wydatków, np. 5 $ miesięcznie.
  3. Wklej klucz (zaczyna się od sk-ant-) poniżej – jest pokazywany tylko raz.
Dokumentacja: platform.claude.com/docs

Gdy skończy się limit

Po błędzie limitu (np. dzienny limit darmowego klucza Gemini) albo braku środków aplikacja sama przechodzi do następnego klucza z listy. Klucz wraca do użycia po resecie limitu – dzienny limit Gemini odnawia się o północy czasu pacyficznego (ok. 9:00 w Polsce).
Uwaga: regulaminy dostawców mogą zabraniać obchodzenia limitów, np. przez zakładanie wielu darmowych projektów tylko w tym celu. Bezpiecznie jest łączyć np. darmowy klucz z płatnym albo klucze z różnych dostawców.
